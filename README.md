## About

This is my personal portfolio, where I present who I am, the projects I'm working on, my education and how to reach me. It is also a hands-on way to practice what I'm learning in my Software Engineering studies.

## Sections

- **About me**: a short introduction.
- **Projects**: planning of a shopping cart system and my first project.

- **Contact**: how to get in touch, in the page footer.

No build step or dependencies needed.

~~~bash
git clone https://github.com/airton-web/YOUR-REPOSITORY-NAME.git
cd YOUR-REPOSITORY-NAME
~~~

Then open `index.html` in your browser.
